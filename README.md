# fstbm-project-learning

Bienvenue dans ce dépôt dédié à notre défi d'apprentissage collectif ! 

Ce projet est né d'une initiative entre étudiants pour pratiquer nos cours en temps réel. L'objectif est simple : transformer nos connaissances théoriques en un projet concret, étape par étape, jusqu'à la fin du module.

## 🎯 L'Objectif
Chaque participant choisit un sujet de site web et le développe au fur et à mesure de l'avancement des cours. Le but ultime est d'avoir un projet complet et fonctionnel à présenter sur **GitHub** et dans notre **Portfolio** à la fin du semestre.

## road_map : La Progression
Nous suivons le programme du module pour faire évoluer nos projets :

1.  **Phase 1 : Structure** - Création du squelette en **HTML**.
2.  **Phase 2 : Style** - Ajout du design avec **CSS**.
3.  **Phase 3 : Interactivité** - Dynamisation avec **JavaScript**.
4.  **Phase 4 : Backend** - Gestion des données avec **PHP** ou **Laravel**.

## ⚠️ Le "Code d'Honneur" (Règles du Jeu)
Pour garantir un apprentissage réel, nous avons établi des règles strictes :

* **🚫 Pas de Triche :** L'objectif est d'apprendre, pas de finir le plus vite possible.
* **🤖 Zéro Copier-Coller d'IA :** L'utilisation de ChatGPT ou autres assistants pour générer du code est interdite.
* **✍️ La Règle de la Frappe :** Si nous devons récupérer un bout de code (documentation, StackOverflow), nous avons l'obligation de **le retaper manuellement** ligne par ligne. Pas de `CTRL+C` / `CTRL+V`. Cela permet d'habituer nos doigts et notre cerveau à la syntaxe ("Welfo lcode").

## 🤝 Motivation & Entraide
Ce groupe existe pour que nous puissions nous motiver mutuellement. Si l'un de nous bloque, on s'entraide, on explique, mais on ne donne pas la solution toute faite.
